# 退稅手帖

給臺灣旅客整理日本購物退稅的手機網頁。拍照留下護照機讀區與收據，在自己的手機上試算門檻、消費稅和出境期限。沒有帳號，也沒有伺服器。

規則依據與最後核對日寫在 [RULES.md](RULES.md)，程式裡的「規則說明」是同一套內容。這不是官方退稅工具，不能代替店家登錄或海關確認。

## 在 iPhone 加入主畫面

1. 用 **Safari** 打開這個網址。用其他瀏覽器時，加入主畫面的支援不一定完整。
2. 點下方的分享按鈕。
3. 選「加入主畫面」。
4. 名稱會是「退稅手帖」。點加入。
5. 之後從主畫面的圖示打開，才是全螢幕，離線也比較穩。

第一次打開需要網路，用來下載頁面和日文辨識語料。載入完成後，已存的行程、收據和辨識可以離線使用。iPhone 若很久沒開、或儲存空間不足，系統有時會清掉網站資料，離開前記得匯出備份。

相機若沒有反應，改按「從相簿選擇」。護照請拍到個人資料頁最下面兩行。收據請拍完整張、避免反光。

## 資料留在哪

行程、護照欄位、收據照片和設定都在這支手機的瀏覽器儲存空間。護照照片辨識完即丟棄，只留你確認過的欄位，號碼可以遮住。

預設不會把照片傳出去。若你在設定裡打開「使用我自己的辨識服務」並貼上金鑰，**只有收據**會送到你填的網址；護照仍然只在手機上讀。

匯出備份可在「更多 → 備份」。金鑰預設不放進備份。

## 在電腦上開發

需要 Node.js 20 以上。

```bash
npm install
npm test
npm run dev
```

開發網址是 `http://127.0.0.1:43123` 。`npm install` 會把辨識引擎複製到本機，日文與英文語料放在 `public/tessdata`。

```bash
npm run build
npm run preview
```

建置結果在 `dist/`，可放到任何靜態網站空間。服務必須走網址開啟（不能用檔案總管直接點開），離線與主畫面才會生效。

## 試算在算什麼

- 2026年11月1日起的退稅方式：先付含稅價，出境確認後由店家或代辦退消費稅。
- 同一店、同一日、未稅合計 5,000 日圓。差一點時會寫出還差多少。
- 10% 與 8%（食品、非酒類飲料）分開算。
- 確認期限是購買日加 90 日（購買日次日起算的第 90 日）。
- 手續費預設不扣。政府不收這筆費用；若店家有扣，在設定裡填百分比。
- 匯率會試著讀公開匯率，失敗時用 2026年11月27日的參考值（1 日圓約 0.2068 新臺幣），可自行修改。這不是銀行牌告。
